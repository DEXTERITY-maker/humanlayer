# Правила проекта

## Общие
- Делаем правильно и надолго. Не MVP, не временные решения.
- Коммиты: Conventional Commits на русском (feat:, fix:, chore:, docs:, refactor:)
- Код: TypeScript строгий, без any (кроме DbRow)

## Dev-сервер
- Dev-сервер ЗАПУСКАЕТСЯ ТОЛЬКО ПО ПРЯМОЙ ПРОСЬБЕ пользователя
- Сервер всегда на порту 3000
- Не перезапускать и не останавливать без спроса
- Для проверки использовать существующий сервер
- Если не отвечает за 5 секунд — сообщить, не пытаться запустить

## База данных
- Миграции ручные, schema в lib/db.ts
- Новые таблицы добавлять в SCHEMA (CREATE TABLE IF NOT EXISTS)
- Индексы добавлять осмысленно (по полям из WHERE)
- BIGINT поля парсить через Number() в мапперах

## Безопасность
- .env.local НЕ коммитить (в .gitignore)
- Токены и пароли в config.example.json с пояснениями
- JWT_SECRET минимум 64 символа
- Все API проверяют сессию через getSessionUserId()

## Фронтенд
- Tailwind классы, без CSS Modules
- Цвета: navy-950, cream, accent-*, mint-*, muted
- Клиентские компоненты: "use client" в первой строке
- SSR где возможно (SEO)
- Не тестировать фронт в браузере без прямой просьбы ("открой в браузере", "проверь визуально")
- Для обычных правок HTML/CSS/JS — только код, визуальную проверку пропускать

## Termux
- shebang не работает: использовать `node node_modules/...` вместо `npx`
- Файлы писать через `cat > file << 'ENDOFFILE'`
- Сборка: `node node_modules/next/dist/bin/next build --webpack`
